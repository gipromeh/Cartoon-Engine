# Cartoon-Engine

**Cartoon-Engine** — проектируемая система подготовки и сборки коротких мультфильмов из отдельных сцен и медиаматериалов по заданной теме и таймлайну.

Цель проекта — превратить творческое задание в воспроизводимый производственный процесс: сценарий → сцены → кадры/изображения → анимация → монтажный таймлайн → итоговый ролик.

## Принципы

- **Сначала спецификация, затем реализация.** Форматы данных и контракты этапов фиксируются до написания движка.
- **Сцена — единица производства.** У каждой сцены есть идентификатор, длительность, описание действия, персонажи, визуальные требования, реплики/титры и список ресурсов.
- **Согласованность персонажей и мира.** Визуальные характеристики фиксируются в character bible и проверяются на протяжении всего фильма.
- **Детерминированная сборка.** Одинаковый набор утверждённых ресурсов и таймлайн должны давать воспроизводимый результат.
- **Заменяемые адаптеры.** Генерация изображений, озвучивание, анимация и рендеринг не должны быть жёстко привязаны к одному поставщику.
- **Контроль качества.** Проверяются полнота ресурсов, длительности, порядок сцен, титры, звук и технические параметры результата.
- **Бесплатный стек как базовый ориентир.** Предпочтение отдаётся open-source инструментам и локальному выполнению; платные сервисы не являются обязательной зависимостью.

## Текущий статус

Зафиксирована архитектура двухфазного производства: сначала утверждение ключевого кадра, затем Image-to-Video, GIF assembly и QC. Исполняемый pipeline и конкретный Image-to-Video backend ещё не реализованы/не выбраны.

## Принципиальное ограничение

ChatGPT может использоваться для генерации исходных изображений по утверждённым промптам. Остальные операции — управление сценами, проверка ресурсов, преобразование форматов, сборка таймлайна, звук, рендеринг и контроль результата — должны быть реализованы отдельными воспроизводимыми инструментами.

## Начало работы

На текущем этапе код запускать не требуется: сначала утверждаются форматы проекта, модель сцены и критерии качества. После этого будет добавлен минимальный вертикальный срез: один короткий мультфильм от описания до готового файла.
