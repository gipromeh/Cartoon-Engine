# TEACHER — CHAR_TEACHER_01

Статус дизайна: APPROVED / LOCKED. Референс: v1.0.

## Структура

- `character.yaml` — канонический паспорт персонажа.
- `REFERENCE/teacher_model_sheet_v1.0.png` — утверждённый исходный модельный лист.
- `RIG/README.md` — проектируемая структура 2.5D rig.
- `POSES/` — будущие утверждённые позы.
- `EXPRESSIONS/` — будущие выражения лица.

## Правило использования

Все новые изображения, позы и сцены с учительницей должны ссылаться на `CHAR_TEACHER_01` и использовать утверждённый reference sheet. Нельзя заменять эталон похожим заново сгенерированным персонажем.

Исходный лист содержит полный паспорт всех персонажей; для работы с учительницей использовать только правую колонку «Учительница». Не использовать соседние изображения девочки и мамы как референсы учительницы.

Дизайн утверждён. Геометрия, rig, IK и анимация пока не реализованы.
